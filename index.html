大樂透好運發球機

Lucky Lotto Popper · 互動式彩球搖號工具
📝 作品簡介 (約100字)
本作品為復古街機風格的互動大樂透搖珠抽獎機，忠實模擬實體彩球在吹氣滾筒內的物理碰撞、浮動與噴射出球動畫。介面結合鮮豔霓虹色彩與即時合成器音效，每次開獎皆帶來滿滿儀式感與視聽震撼，支援一鍵搖號與開獎彩票存根生成。
⚙️ 使用到的 API 與核心技術
⚡ HTML5 Canvas 2D API 🔊 Web Audio API (合成器音效) 🔄 requestAnimationFrame (物理運動) 🎨 Tailwind CSS & Keyframe Animations 👆 Touch & Pointer Events

沉浸式風景大時鐘

Immersive Landscape Clock · 極簡高畫質動態時鐘
📝 作品簡介 (約100字)
本作品為極簡優雅的沉浸式風景大時鐘，精選全球高解析度自然絕景作為動態背景，支援 Ken Burns 微縮放與平滑淡入淡出切換。結合毛玻璃質感資訊面板、大字體時間顯示與多種自訂模式，無論放置於桌上立架或大螢幕展示皆賞心悅目。
⚙️ 使用到的 API 與核心技術
🖥️ Fullscreen API (全螢幕模式) ⏱️ Date & Timing API (精準秒級時脈) ✨ CSS3 Ken Burns & Crossfade 動畫 ⌨️ Keyboard Event API (全螢幕與換景快捷鍵) 🔮 Glassmorphism 毛玻璃視覺設計
🎯 應用場景
  • ▸ 辦公桌面平板與閒置手機長亮翻頁桌面鐘
  • ▸ 個人專注工作、研讀書籍之沉浸番茄鐘背景
  • ▸ 客廳智慧電視大螢幕或展演空間環境氛圍時鐘
  • ▸ 實體會議開場倒數與簡報演講計時提示
